# Contributing / Mitwirken / 参与完善

English, German and Chinese contributions are welcome. The project combines domain work with AI-assisted implementation; every proposed change still needs review and evidence.

## A useful report

1. State the version, environment and exact steps.
2. Supply the smallest **fictional** example that reproduces the behavior.
3. Separate expected behavior from actual behavior. For a tax-rule correction, include jurisdiction, applicable period, official source and the relevant passage.
4. Explain the practical effect: incorrect result, missing fact, unclear wording or extra work.

Never attach client workbooks, real tax IDs, contact lists, credentials or saved projects containing real source data. Replace the underlying facts with invented data, including hidden sheets, formulas, comments and metadata. A screenshot with a covered name may still disclose information.

Maintainers will classify feedback as reproducible defect, rule/source review, usability, enhancement or insufficient information. Reports are reviewed weekly. That is a review cadence, not a guaranteed resolution deadline. A useful fix includes a focused regression check and updated documentation. Pull requests should explain what changes and how it was verified. Contributor work must be compatible with the repository's MIT license and retained third-party notices.

**Deutsch:** Bitte Version, Umgebung, Schritte, fiktive Eingaben und erwartetes/tatsächliches Ergebnis nennen. Bei Rechtsfragen zusätzlich Land, Zeitraum und amtliche Quelle. Keine Mandantendaten oder Zugangsdaten veröffentlichen. Rückmeldungen werden wöchentlich gesichtet; daraus folgt keine feste Behebungsfrist.

**中文：**请提供版本、环境、步骤、虚构输入及预期/实际结果；法规问题另附国家、适用期间和官方来源。不要上传客户文件、真实税号或凭证。每周整理反馈，但不承诺固定修复期限。
